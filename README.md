# Бутылка

Караоке за столом. Сначала кладёшь 1–3 своих трека — слышишь файл как есть, колода лежит на устройстве. Бутылка крутит уже твою колоду.

Круг бреда и Suno — следующим слоем, когда живой звук на месте.

## Запуск

```bash
cp .env.example .env.local
# SUNO_API_KEY пока не обязателен для своих файлов
npm install
npm run dev
```

Открой обычной вкладкой, не превью в iframe.

## Выложить

[Vercel](https://vercel.com) → Import репозитория. Для кухни Suno добавь `SUNO_API_KEY`.
