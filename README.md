# Бутылка

Караоке за столом. Сначала каждый пишет строчку бреда за 10 секунд. Кухня варит из этого песню. Пока ждёте — поёте народные и свои треки. Когда бутылка чернеет, поёт тот, на кого указала.

## Запуск

```bash
cp .env.example .env.local
# впиши SUNO_API_KEY (sunoapi.org) и по желанию XAI_API_KEY
npm install
npm run dev
```

Открой `http://localhost:8080`.

## Что внутри

- круг бреда → ИИ пишет текст → Suno варит трек и минус
- колода «все знают»: народные и XIX век, без чужих хитов
- свой mp3 + текст, минус снимается при пении
- ноты, подарки, общий и личный чат

Хиты вроде «Смуглянки» в колоду не кладём — только своим файлом.

## Выложить в интернет

Это не GitHub Pages: нужен сервер (Suno ходит с бэка). Самый прямой путь — [Vercel](https://vercel.com) → Import этого репозитория. В Environment Variables добавь:

- `SUNO_API_KEY`
- `XAI_API_KEY` (необязательно, без него текст песни соберётся локально)

Свой домен или `*.vercel.app` открывается обычной вкладкой — звук на ноуте так ведёт себя спокойнее, чем во встроенном превью.
